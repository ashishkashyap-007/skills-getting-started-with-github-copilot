# OctoAcme Project Management Docs

This folder is the entry point for OctoAcme's project management knowledge base. It contains the process documentation that teams use to plan, execute, and continuously improve their work.

## Overview

OctoAcme follows an iterative, customer-first delivery model with clear ownership and data-informed decisions. Projects progress through five lifecycle phases: **Project Initiation → Project Planning → Execution & Tracking → Release & Deployment → Retrospective & Continuous Improvement**, supported by defined roles, risk management, and regular communication cadences.
